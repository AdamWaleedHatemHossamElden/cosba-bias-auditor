# Application Screenshot Guide

This directory contains genuine CoS-BA Bias Auditor screenshots captured from the running local application during final QA. Disposable demonstration accounts and records were used and removed from the local database after capture.

The root README references these captures:

| Filename | Suggested capture |
| --- | --- |
| `home.png` | Landing page and project introduction |
| `feed.png` | Community feed with search/filter controls and content cards |
| `content-detail.png` | Submission metadata, reactions, and discussion |
| `bias-report.png` | Primary/secondary bias category report form |
| `dashboard.png` | Aggregate charts and insight cards populated with representative local data |
| `admin.png` | Moderation dashboard with non-sensitive example records |

The screenshots use a consistent 1440×900 desktop viewport and contain no passwords, tokens, or personal email addresses.
